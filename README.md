# Атлас масштабов жизни

Интерактивная шкала размеров живого: от атома водорода (0,24 нм) до подводного луга посидонии длиной 180 км.
262 объекта в 18 разделах, все нарисованы в одном масштабе — каждый следующий шаг крупнее предыдущего.

**Сайт:** https://berengow.github.io/atlas-masshtabov-zhizni/

## Что внутри

- **Атомы жизни** — модель атома с электронами по оболочкам, электронная конфигурация, доля в массе тела.
- **Молекулы** — около 100 штук: все 22 протеиногенные аминокислоты (кодоны, класс боковой цепи, незаменимость), сахара, нуклеотиды и коферменты, липиды и пигменты, гормоны и нейромедиаторы, витамины, кофеин, аспирин и другие. Вращаемые 3D-модели.
- **Белки и молекулярные машины** — 3D-структуры из PDB: гемоглобин, GFP, антитело, нуклеосома, спайк-белок коронавируса, шаперонин GroEL и другие.
- **Вирусы, органеллы, бактерии и археи, клетки человека, протисты, грибы и пыльца, микроживотные, животные и великаны.**

У каждого объекта — описание, факты, характеристики, сравнение размеров («в N раз больше…»), блок «Положить рядом» для сравнения любых двух объектов в масштабе, фото или 3D-модель.

Управление: колесо мыши, перетаскивание, стрелки ←/→, `Enter` — подробности, `/` — каталог с поиском. Есть автоматический тур, случайный объект и два режима микроскопа: «светлое поле» (цвета окраски гематоксилин-эозин) и «флуоресценция».

## Устройство

Сайт — один статический файл `docs/index.html` (canvas + чистый JavaScript) и папки `docs/img`, `docs/pdb`. 3D-модели показываются библиотекой [3Dmol.js](https://3dmol.org) с jsDelivr. Ничего собирать для просмотра не нужно — достаточно открыть `docs/` любым статическим сервером:

```bash
python -m http.server 8765 --directory docs
```

### Пересборка

Контент (названия, описания, факты, размеры) лежит в `build/content.py`, оформление и логика — в `build/template.html`.

```bash
pip install pillow numpy
python build/fetch.py   # скачивает структуры, фото и силуэты в downloads/ (кэш, долго)
python build/make.py    # собирает site/ и docs/, обновляет CREDITS.md
```

`make.py` использует метаданные из `build/fetched.json` и уже лежащие в `docs/` изображения и структуры, поэтому для правки текстов и оформления `fetch.py` запускать не нужно — только при добавлении новых объектов.
